# Rawi

Rawi transforme des planches de BD en vidéos motion comic, en local et hors ligne.

- `apps/rawi` : BD → motion comic (v0.1 fonctionnelle)
- `packages/embedkit` : socle d'IA embarquée réutilisable (à créer, jalon M0)
- `docs/PRD.md` : exigences produit — à lire en premier
- `docs/adr/` : décisions d'architecture
- `CLAUDE.md` : règles de travail pour Claude Code

Démarrage rapide : voir `apps/rawi/README.md`.
